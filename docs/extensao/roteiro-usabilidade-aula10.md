# Roteiro de usabilidade — Aula 10

Este roteiro deve ser aplicado a uma pessoa que não participou do desenvolvimento. A pessoa deve usar a interface sem consultar o código. Use somente dados fictícios e não registre informações pessoais do participante.

## Preparação

- [ ] Iniciar o back-end e o front-end.
- [ ] Abrir a aplicação em uma janela de navegador com largura de celular.
- [ ] Explicar apenas a tarefa, sem orientar onde clicar.

## Tarefas e observações

| Verificação | Resultado / observações |
|---|---|
| A pessoa consegue cadastrar um beneficiário fictício em até 30 segundos? | Pendente |
| Se houver erro no formulário, a mensagem explica como corrigir? | Pendente |
| A pessoa consegue navegar e concluir ações usando somente Tab, Shift+Tab, Enter e Espaço? | Pendente |
| A pessoa consegue localizar e usar edição e exclusão com confirmação? | Pendente |
| A interface continua legível e utilizável em uma tela estreita? | Pendente |
| Há texto, foco ou controles difíceis de perceber? | Pendente |

## Registro após aplicar

- **Data:** pendente
- **Perfil do participante (sem nome):** pendente
- **Dificuldades observadas:** pendente
- **Sugestões recebidas:** pendente
- **Ajustes feitos após o teste:** pendente
- **Contraste:** conferir com ferramenta automática como apoio e registrar os pontos que exigirem correção.

> Não marque a atividade como concluída até aplicar o roteiro e registrar observações reais. Uma execução automatizada não substitui a validação com outra pessoa.
